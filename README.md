## Golden rules that work in any college

### 🎯 Consistency > Intensity

2 focused hours daily beats a 12-hour weekend binge. Build the streak first.

### 🛠 Build, don't just watch

For every 5 hours of tutorials, build something. Projects are your real resume.

### 🌍 College tag ≠ destiny

Skills, projects and problem-solving decide interviews. Tier-3 to top MNC is possible.

### 🤝 Learn in public

Use GitHub, LinkedIn and blogs. Visibility brings referrals and opportunities.

## Year-by-year game plan

### Year 1 · Foundation

C + Python, logic building, Git/GitHub, one tiny project a month. Explore clubs. Don't chase five things at once.

### Year 2 · Skills

DSA + OOP + DBMS, web basics, start LeetCode, first hackathon, first real project.

### Year 3 · Proof

Internship, 2 strong projects, 200+ DSA problems, core CS revision, resume and LinkedIn polished.

### Year 4 · Convert

Mock interviews, off-campus referrals, offer negotiation, or GATE / MS applications.

## Your college, your edge

### 🏛 IITs · NITs · IIITs

Use the ecosystem: research profs, clubs, alumni referrals, hackathons. Don't lean only on campus drives; build depth.

### 🚀 Tier-2 / Tier-3

Skills beat tags. DSA + projects + GitHub, apply off-campus from Year 3, cold-message on LinkedIn, try remote internships and open source.

### 🔁 Non-CSE branches

Same roadmaps work. Add one portfolio project that mixes your core branch with code.

DSA · 2 min read

### Start DSA in 30 days

A simple month-one plan that works from any college.

Read

Week 1: pick one language, learn arrays and strings. Week 2: hashing, two pointers, recursion. Week 3: linked lists, stacks, queues, binary search. Week 4: tree basics. Solve 2 problems daily, write down every mistake, and revise on Sundays.

Careers · 2 min read

### Tier-3 college to top company: what matters

Your campus tag opens fewer doors, but skills open the rest.

Read

Recruiters mostly check three things: can you solve problems, can you show real projects, and can you communicate clearly. Build DSA depth, ship projects with live links, keep a clean GitHub and LinkedIn, and apply off-campus from Year 3 with referrals wherever possible.

Projects · 2 min read

### 5 beginner projects recruiters remember

Pick projects that look like real products.

Read

1\) A deployed portfolio site. 2) A full-stack app with login and a database. 3) A clone of a known app with one original feature. 4) A tool or bot that real people actually use. 5) A small ML app with a live demo. Always add a README with screenshots and a live link.
